# 랜덤 자리 뽑기

교실 자리 배치 도구 겸 **무작위 실험실**입니다.
자리를 뽑고, 그 무작위가 정말 공정한지 학생과 함께 직접 확인해 볼 수 있습니다.

> **원작 © 2026 민준서 · 개작 © 2026 티쳐무 · 모든 권리 보유**
> 민준서 님이 만든 「랜덤 자리 뽑기」를 원저작자의 허락을 받아 수업용으로 다시 만들었습니다.

---

## 3줄 사용법

1. 열·행 슬라이더로 우리 교실 모양을 맞춥니다. (쓰지 않는 자리는 [없는 자리 설정]으로 뺍니다)
2. **[🎲 뽑기!]** 를 누릅니다. 결과는 [🖨 인쇄]로 그대로 뽑을 수 있습니다.
3. 학생이 「또 쟤랑 짝이야?」라고 하면 **[🔬 공정성 실험실]** 을 열어 보여 주세요.

## 「또 쟤랑 짝이야?」 — 이 앱을 다시 만든 까닭

원작의 뽑기가 치우친 게 아닌지 확인하는 데서 시작했습니다. **결과는 「치우치지 않았다」였습니다.**

원작은 「이미 뽑은 번호면 다시 뽑기」(거부 표집) 방식이었는데, 흔히 편향을 의심받지만
수학적으로 완전히 균등합니다. 실제로 확인했습니다.

| 검사 | 결과 |
|---|---|
| n=6, 순열 720가지 × 72만 회 | 카이제곱 766.7 (자유도 719), **z = 1.26** ✅ |
| 30자리 「학생 × 자리」 교차표 × 20만 회 | 카이제곱 814.5 (자유도 841), **z = −0.65** ✅ |
| 특정 두 사람이 짝이 될 확률 | 실측 5.586% vs 이론 5.517% ✅ |

**그런데 학생들 말도 맞습니다.** 30명 학급에서 한 학기에 열 번 자리를 새로 뽑으면,
완전히 공정한 무작위인데도 이렇게 됩니다. (2만 학기 시뮬레이션)

| 학기 중 벌어지는 일 | 평균 |
|---|---|
| 2번 이상 짝이 된 조합 | **44.4쌍** (전체 435쌍 중) |
| 3번 이상 짝이 된 조합 | 6.5쌍 |
| **같은 자리에 2번 이상** 앉은 학생 | **24.5명 / 30명** |
| 10번 중 5번 이상 뒷줄에 앉은 학생 | 6.4명 |

> **버그가 아닙니다. 공정한 무작위는 원래 이렇게 뭉칩니다.**
> 사람은 무작위를 「고르게 흩어진 것」이라 생각하지만, 고르게 흩어 놓으려면 오히려 손을 대야 합니다.

그래서 두 가지를 모두 넣었습니다 — 기본은 **완전 무작위**(수학적으로 공정),
스위치로 **[최근 짝·구역 피하기]**(교실에서 바라는 골고루). 실측 효과는 이렇습니다.

| 한 학기에 | 완전 무작위 | 피하기 켬 | |
|---|---|---|---|
| 2번 이상 짝이 된 조합 | 44.3쌍 | 23.9쌍 | −46% |
| **3번 이상 짝이 된 조합** | 6.6쌍 | **0.22쌍** | **−97%** |
| 같은 자리에 2번 이상 | 24.5명 | 18.7명 | −24% |

교실에서 실제로 불만이 나오는 「3번 이상 같은 짝」이 거의 사라집니다.

⚠ 다만 **피하기를 켜면 더 이상 균등한 무작위가 아닙니다.** 앱은 이 사실을 화면에 밝힙니다.

## 무엇을 기억하고, 무엇을 기억하지 않나

이름도 학번도 받지 않습니다. **서버가 없습니다.**

- 기억하는 것: 「몇 번이 몇 번 자리에 앉았는가」 + 그때의 격자 크기. 최근 **5회**분.
- 저장 위치: 그 브라우저의 `localStorage`. 어디로도 보내지지 않습니다.
- ⚠ 브라우저나 PC 를 바꾸면 기억이 없습니다 → **[⬇ 파일로 내보내기]** 로 옮기세요.
- 언제든 **[🗑 기억 지우기]** 로 한 번에 비웁니다.

## 이미 쓰던 한글 자리배치표를 이력으로 넣기

한글(.hwp/.hwpx) 자리배치표가 쌓여 있다면 그대로 이력으로 쓸 수 있습니다.

```bash
pip install olefile lxml
python tools/hwp-이력.py "자리배치표가 있는 폴더" -o 자리이력.json
```

만들어진 `자리이력.json` 을 앱의 **[📁 기억해 둔 지난 배치] → [⬆ 파일 불러오기]** 에 넣으면
교실 모양(열·행·통로·없는 자리)까지 그대로 이어받습니다.

- 명단표의 `번호`·`이름` 을 읽어 **이름을 번호로 바꿔 담습니다. 결과 파일에 이름은 없습니다.**
- 사람이 앉지 않는 **통로 열은 「없는 자리」로 남깁니다.** 통로를 지우고 붙이면
  통로 건너편 사람이 짝으로 잡혀 버립니다.
- **교탁이 표 아래에 있으면 행을 뒤집습니다**(교사 시점 → 앱은 교탁이 위).
- 학생 행에 **가로 병합이 섞인 파일은 건너뜁니다.** 열 위치를 믿을 수 없기 때문입니다.
- 앱은 **가장 최근 5회분**만 보관합니다.

⚠ 만들어진 `자리이력.json` 은 이름이 없어도 실제 학급의 자리 기록입니다.
공개 저장소에 올리지 마세요 (`.gitignore` 가 막고 있습니다).

## 설치와 실행

```bash
npm install
```

| 명령 | 하는 일 |
|---|---|
| `npm start` | 개발 서버 (http://localhost:5173) |
| `npm run build` | `dist/index.html` 한 파일로 빌드 |
| `npm test` | 113가지 시험 |
| `npm run check:syntax` | 소스 19개 전수 검사 (문법 · 저작권 · 화면 수명 · 기본 대화상자) |

빌드 결과는 **`dist/index.html` 한 파일**(약 38KB)입니다.
외부 자원을 하나도 부르지 않으므로 **더블클릭만으로 열립니다.**
인터넷이 없는 교실에서도 그대로 씁니다.

> ⚠ 저장소 루트의 `index.html` 은 개발용 껍데기라 그냥 열면 흰 화면입니다.
> 나눠 줄 것은 `dist/index.html` 입니다.

## 수업에서 쓰기

- **확률·통계 단원** — 실험 ⓑ 가 「생일 문제」와 같은 이치를 자리로 보여 줍니다.
- **시뮬레이션** — 실험 ⓐ 의 카이제곱으로 「고르다」를 수치로 판정합니다.
- **알고리즘** — 원작의 거부 표집과 피셔–예이츠를 견주면 「같은 답, 다른 비용」이 드러납니다.
  (30자리 기준 평균 120번 vs 정확히 29번)
- **컴퓨팅 사고** — 「공정」과 「골고루」가 다르다는 것, 그리고 그것이 설계 선택이라는 것.
